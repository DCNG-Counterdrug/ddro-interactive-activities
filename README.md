# DDRO Interactive Activities

A home for facilitator-led interactive prevention education activities. These experiences are designed to be projected in a group setting; the facilitator clicks the choices selected by students.

## Site
After GitHub Pages is enabled, the homepage will be at:
https://blynum.github.io/ddro-interactive-activities/

## Current activity
- **Skit 1 — Basketball Break**: `activities/skit-1.html` (original Twine 2 / Harlowe 3 export; upload separately).
- This Twine story includes 11 passages and branching choices, with audio narration and a referenced image.
- The original HTML still links to media hosted on `belital2.sg-host.com` and `ngddro.siterubix.com`. Those links are **not** part of this repository; audio/image playback is not guaranteed.

## Adding stories
1. Export a Twine story as a standalone HTML file.
2. Upload it into the `activities/` folder with a readable filename such as `skit-1.html`.
3. Add a link from `index.html`.
4. Add recovered assets to `audio/` and `images/` and update media paths in the Twine source before exporting again.

## GitHub Pages
In **Settings → Pages**, select **Deploy from a branch** and choose **main** and **/(root)**. Save. It may take a few minutes for the published site to appear.

## Public visibility
This is a **public repository**, including any future uploaded activity text, source files, audio, and images. Do not upload sensitive or restricted government information, private student data, or third-party materials without distribution rights.
